本地 AI 编程用量看板

AI 编程花了多少，
本地看个明白。

AgyToken 把 Google Antigravity、OpenAI Codex 与 Claude Code 的本地使用记录汇总成一个简洁看板：看 Token、看趋势、看估算费用，但不上传你的会话内容。

查看源代码隐私说明

研发动机，是让 AI 编程的成本重新可见。

越来越多的开发工作在 Codex、Claude Code 和 Antigravity 等工具中完成，但使用量分散在不同的会话目录、数据库和日志格式里。人们很容易知道“今天用了很多”，却很难说清究竟是输入上下文、输出代码、缓存命中还是推理过程带来了消耗，更难把它们放到同一时间尺度上理解。

AgyToken 想解决的不是替服务商计费，而是为个人提供一块诚实的本地仪表盘。它将已有的本地使用记录整理成能浏览、筛选和回看的统计，让使用者看到自己在不同工具与不同阶段的真实工作节奏，而不是把开发记录再次交给另一个收集数据的在线平台。

数据采集从各工具已经存在的本地痕迹开始。

Codex 的会话以 JSONL 形式保存在本地目录中，AgyToken 会从会话元数据与尾部用量快照提取输入、缓存、输出和推理 Token；Claude Code 的项目会话包含标准 usage 元数据，可以按模型与轮次累加；Antigravity 则需要同时处理客户端与命令行端留下的 SQLite 数据和生成元信息。不同来源并不强行伪装成完全相同的数据，而是在统一视图中保留各自可获得的精度。

扫描器用 Python 完成解析、缓存和增量更新，把复杂的本地文件格式隔离在一个可审查的层里；macOS 前端使用 SwiftUI，负责窗口状态、时间筛选、表格详情和趋势图交互。这样的划分既方便跟随上游工具的日志格式变化，也让桌面体验保持原生、流畅且不依赖浏览器标签页。

价格计算应当有用，但不能伪装成账单。

应用将模型价格目录作为可更新的本地数据源，并把输入、输出和缓存命中的不同费率纳入估算。这样做可以让一段使用量在今天、近七天或自定义日期范围内形成可比较的成本参考，也可以帮助发现某个模型或工作流是否突然改变了消耗结构。

不过，最终账单仍由服务商决定。模型别名、套餐、订阅额度、区域定价、折扣和后台计费口径都可能使实际费用与本地估算不同。AgyToken 在设计上把费用定位为解释 Token 行为的辅助视图，而非替代官方对账；附带的 NOTICE 也清楚标记了价格目录的上游来源与归属边界。

本地优先不是宣传语，而是明确的处理边界。

AgyToken 不要求账号，不建立自己的云端数据库，也不把会话正文上传到外部服务。刷新、过滤、搜索和图表生成都在当前 Mac 上完成。它会记住窗口位置、筛选条件、币种和图表状态，是为了减少重复设置，而不是为了追踪使用者。

项目适合同时使用多种 AI 编程助手，并希望保有记录控制权的开发者。可以构建原生 App，也可以审查并直接运行 Python 扫描器。README 描述了本地目录读取方式、启动与打包流程；开源代码让每一条统计路径都可以被检查、修正或扩展。
