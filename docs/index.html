Local AI coding telemetry

AI 编程花了多少，
本地看个明白。

AgyToken 把 Google Antigravity、OpenAI Codex 与 Claude Code 的本地使用记录汇总成一个简洁看板：看 Token、看趋势、看估算费用，但不上传你的会话内容。

查看源代码隐私说明

不用把开发记录再交给一个云端服务。

应用直接读取各工具已经存在于你电脑中的本地会话数据，生成你自己的使用量视图；刷新、过滤和浏览都在本机完成。

三类工具，一处总览

在 Antigravity、Codex、Claude Code 与全部工具之间切换，避免在不同界面来回查找。

Token 拆分

分别呈现输入、输出、缓存命中和推理 Token，知道消耗究竟来自哪里。

趋势不止是数字

按天观察总用量和输出量，峰值与阶段性变化更容易被发现。

灵活时间范围

今天、昨天、近 7 天、近 30 天、全部历史，或自定义的任意日期区间。

费用参考

根据随应用附带、可更新的模型价格目录估算费用；原始定价来源可追溯。

记住你的视图

保留窗口位置、筛选条件、币种、图表状态和自动刷新偏好，下一次无需重设。

数据在你的机器上。

AgyToken 读取本机的会话目录或数据库来做统计。它不需要账号，也不把会话文本同步到自己的服务器。费用为估算值，最终以各服务商账单为准。
